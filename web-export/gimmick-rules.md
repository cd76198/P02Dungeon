기본 공격은 피해 34, 전방 오프셋 140 cm, 검사 반경 170 cm, 쿨다운 0.35초다. E를 누르는 동안 공격을 억제한다. 템플릿의 Space 점프 입력은 남아 있어도 런타임 JumpMaxCount=0, JumpZVelocity=0이며 대시 입력도 false로 고정되어 있다.

`BP_LevelTransition` 에셋에는 BeginOverlap → OpenLevel(`L_Interior_FinalBossCandidates_TEST`) 그래프가 존재하지만 이번 두 맵에 배치된 전환 액터는 아니다. 실제 필드 전환은 `P02OutdoorReviewController_0`의 C++ 좌표 조건이며 목적지는 보수 전 던전이다. `BP_CombatCharacter`와 GameMode는 폰·이동 입력을 제공하고, 실제 카메라/HUD/기믹은 네이티브 subsystem이 생성한다.

실행 검증: PIE 초기 상태, 네이티브 함수를 직접 호출한 다리 8타격·낙하·복구, 중간보스 체력 실측, 직접 피해로 처치한 뒤 레버 표시·Blocker 충돌 해제. 이 검증은 키보드로 처음부터 끝까지 플레이한 완주 검증이 아니다. 문 E 홀드, 색 순서 성공/오답/60초 재시도, 필드 전환은 소스 분석 기준이며 전체 입력 시나리오는 실행 검증하지 않았다.

추격자·오답 적은 고정 Name 없이 지연 스폰되므로 개별 인스턴스의 정확한 이름은 실행 시 생성된다. 초기 GLB에는 아직 생성되지 않은 적이 없으며, interactive-objects.json의 later_spawned_enemies에 생성 위치·클래스·형상 재사용 기준과 미확인 이름을 기록했다. 웹에서는 적마다 별도 메시 인스턴스를 생성해야 한다.
