# 영상과 프로젝트 비교

영상: https://youtu.be/d1TWflW1VhE . 아래 시점의 화면·자막을 샘플링해 확인했다. 전체 프레임이나 입력·충돌 로그는 확보하지 않았으므로 화면에 없는 내부 조건을 영상으로 검증했다고 표시하지 않는다.

| 시점 | 확인한 영상 표현 | 현재 소스·실행 |
|---|---|---|
| 0:42 | 길을 따라 이동 | 최신 보수 맵의 전체 배치가 영상 제작 당시와 동일한지 미확인 |
| 1:03 | 방해몬스터 스폰 시작 | SpawnVolume의 X 경계 통과 시 추격 개시. Y/Z는 검사하지 않음 |
| 1:24 | 다리 8회 피격 시 파괴·스폰 중지 | 코드와 PIE 직접 타격 시험 일치. 레버 복구 후에도 추격 중지 유지 |
| 1:45 | 문 개방 직후 중간보스 조우 | 문은 E 5초 홀드. 코드상 다리 파괴 여부를 필수 조건으로 검사하지 않음 |
| 1:51 | 중간보스 처치 2초 후 하층 계단 생성 | 코드에서 2초 대기는 일치. 현재 LowerDistance=0이므로 배치된 계단 위 Blocker를 제거하는 방식 |
| 1:56 | 레버 생성 | 코드에서는 보스 사망 직후 레버 표시, 계단 장치는 2초 후 시작. 편집 영상만으로 정확한 동시성은 확정 불가 |
| 2:06 | 부서진 다리 복구로 힌트 재확인 | 현재 레버 E는 다리 Restore만 수행. 계단은 자동 처리 |
| 2:27 / 2:48 | 하층·최종구역으로 이동 | 실제 층별 충돌은 추출했으나 전체 보행 완주 미검증 |
| 3:04 / 3:09 | 오답 시 상호작용 비활성화 및 페널티 몬스터 소환 | 코드상 적 3개. 모두 처치 외에도 60초 초과 시 해제되는 조건이 존재하며 해당 영상 구간에서는 시간 제한 확인 불가 |
| 3:19 | 기믹 성공 시 최종 출구 개방 | 정답 Blue→Red→Green. 최종문 2개 메시를 각각 움직이고 숨겨야 함 |

영상의 적은 회색 블록으로 보였고 현재 네이티브 코드는 일반 적을 붉은색 C97A7A, 중간보스를 A84F4F로 지정한다. 현재 실행에서 최대체력 34/초기체력 100 차이를 확인했지만 영상만으로 당시 내부 체력을 판정할 수 없다.
