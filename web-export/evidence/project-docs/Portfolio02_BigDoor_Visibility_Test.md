# Portfolio 02 — Big Door 선노출 고정 쿼터뷰 테스트

테스트일: 2026-08-25  
상태: **TEST VALUE / 미확정**

이번 메시지에는 언급된 참고 이미지 2장의 실제 파일이 포함되지 않아, 아래 수치는 최종 레이아웃이 아닌 빠른 가시성 비교값으로만 사용했다. 기존 `L_Entrance_v03`은 변경하지 않았다.

## 공통 조건

- Camera: Perspective / Pitch `-50°` / Yaw `0°` / Distance `1700uu` / FOV `45`
- PlayerStart: `(0, 0, 100)`
- Big Door 평면 위치: `X=1500uu`
- 중간 가림 구조 위치: `X=900uu`
- Big Door 기본 크기: 폭 약 `1050uu`, 높이 약 `900uu`
- 모든 테스트 액터: `MCP_TEST_` prefix

## A — 기본 Big Door

- 보이는 정도: 시작 화면에서 보이지 않음.
- 무엇이 가리는지: 중간 벽에 가려진 수준이 아니라 문과 중간 벽 모두 고정 카메라 프레임 밖에 있음.
- 장기 목표 인지 가능 여부: 불가능.
- Screenshot: `Saved/Screenshots/P02_BigDoor_A.png`

## C — 상부 높이 증가

- 보이는 정도: 상부 실루엣을 약 `1325uu`까지 높였지만 시작 화면에서 보이지 않음.
- 무엇이 가리는지: A와 마찬가지로 고정 카메라 프레임 밖에 있음.
- 장기 목표 인지 가능 여부: 불가능.
- Screenshot: `Saved/Screenshots/P02_BigDoor_C.png`

## E — 가림 구조 최소 조정

- 보이는 정도: 시작 화면에서 보이지 않음.
- 조정 내용: Big Door는 A와 동일. 중간 벽 높이만 `700uu → 450uu`로 축소.
- 장기 목표 인지 가능 여부: 불가능.
- Screenshot: `Saved/Screenshots/P02_BigDoor_E.png`

## 비교 결론

**현재 TEST 위치에서는 어느 방식도 자연스럽지 않음.**

상부 프레임을 높이거나 중간 벽 높이를 줄여도 차이가 없었다. 이번 결과에서 직접 확인된 원인은 가림 구조가 아니라 Big Door의 테스트 평면 위치 자체가 Entrance 시작 카메라 프레임 밖이라는 점이다. 카메라 값은 변경하지 않았다.

## 사용자 판단 필요

- 실제 참고 이미지에 대응하는 Big Door의 평면 위치와 Entrance 사이 거리.
- `X=1500uu`보다 가까운 위치를 추가 비교할지 여부.
- Entrance에서 선공개하지 않는 방향으로 결론낼지 여부.

이번 결과만으로 실제 내부 레이아웃의 최종 결론을 확정하지 않는다.
