## Transition Mid Boss 재노출 — 기하 계산 (2026-08-26, 레벨 미변경)

레벨은 수정하지 않았다. 고정 카메라와 실측 좌표만으로 재노출 가능 여부를 계산했다.

### 입력값 (모두 실측)

- 카메라: Perspective / Pitch `-50°` / Yaw `0°` / Distance `1700uu` / FOV `45` (수평)
  → 반각 수평 `22.50°`, 수직 `13.12°` (16:9). 카메라는 플레이어보다 X `-1093uu`, Z `+1302uu`.
- Mid Boss 바닥(SMA_5): X `700~3400`, Y `-2200~-200`, 상단 Z `0`
- Mid Boss +Y 경계벽(SMA_7/8): Y `-150`, 상단 Z `350`, 출구 프레임 개구부 X `2400~3050`
- Transition 높은 경로(SMA_20): X `3000~5600`, Y `700~1500`, 상단 Z `240`
- 계단참(SMA_19): X `2200~3000`, Y `700~1500`

**모델 검증** — 같은 계산으로 `(7000,1100,340)` 에서 중앙 구조물 상단이 수직 `11.0°`(한계 `13.12°`)에 잡힌다. 08-25 리포트의 "상단 프레임에 가깝게 크게 잡힘" 관찰과 일치한다.

## 가능한 문제

난간·벽 높이로는 해결되지 않는다. 두 제약이 **동시에 만족될 수 없는 상태**다.

- **FOV 제약** — 화면에 들어오려면 `측면편차 ≤ 0.414 × 전방거리`. 계단참 기준 Mid Boss 바닥 깊이가 `Y ≥ -747` 이어야 한다.
- **벽 가림 제약** — 경계벽(Y `-150`, 상단 `350`)을 넘긴 시선이 바닥에 닿는 최소 깊이는 `Y ≤ -481`.
- 현재 카메라 Y `1140` 에서 두 조건의 교집합은 **공집합**. Mid Boss 방의 최대 X 가 `3400` 인데, 깊이 `Y=-481` 을 화면에 넣으려면 대상 X 가 `5557` 이상 필요하다 (**2157uu 부족**).

근본 원인은 벽 높이가 아니라 **평면 위상**이다. Yaw `0°` 고정 카메라는 항상 +X 를 본다. 진행축이 단조 +X 이면 지나온 공간은 언제나 카메라 뒤쪽에 남는다. 재노출은 **지나온 공간의 일부가 관찰 지점보다 +X 앞쪽에 있을 때만** 성립한다.
