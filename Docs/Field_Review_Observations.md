# 필드 이동 검증에서 발견한 추가 검토 사항

두 사례 모두 참가자 8명·15판의 행동 통계가 아니라 기술 이동 검사의 결과다. 발생 건수를 참가자 수나 사용자 실패율로 쓰지 않는다. 현재 자료는 작업노트의 관찰 기록이며 당시 상세 원시 검사 폴더는 저장소에 없다.

| 항목 | 실제 관찰·확인 | 당시 처리 | 해석의 한계 |
|---|---|---|---|
| 관찰 구간 외곽 경계벽 M081 | 20개 구간 × 5개 이동 조건 중 99 PASS, 1 REVIEW. 경계벽 방향 입력에서 정체했으나 바깥쪽 방향 전환 후 통과 | 영구 끼임 미확인, 당시 맵 수정 없음 | 100명 또는 100회 전체 맵 완주 결과가 아님. 현재 최종 맵에서도 같은 결함이 남아 있다는 뜻은 아님 |
| 분수 재합류 구간 계단 측면 | v09-11_A 검증 초기 이동 2건에서 계단 옆면 단차에 정체. 기존 정면 접근 경로는 통과, 던전 전환 확인 | 당시 계단 측면을 변경하지 않고 상세 보고에 기록 | 측면 정체는 관찰된 사실이나 모든 접근의 통행 불가·일반 사용자의 길찾기 실패로 확장할 근거는 없음 |

근거: [진입 구간 작업노트](Portfolio02_Entrance_Design_Log.md)의 2026-09-10 ‘100개 이동 조건 자동 검사’(L2273–2278), 2026-09-14 ‘v09-11_A 분수 재합류 마당 확장·난간 정리’(L2412–2419).

소개서 문구 제안: “기술 이동 검사에서 특정 접근 방향의 정체가 확인됐으나, 방향 전환 또는 정면 접근으로 통과했다. 해당 기록만으로 영구 끼임이나 전반적인 진행 불가를 확정하지 않았으며 당시 관찰 사항으로 남겼다.” 이는 현재 자료에 근거한 표현 제안으로, 기록에 없는 당시의 설계 의사결정 이유를 새로 만든 것은 아니다.
